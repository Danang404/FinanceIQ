**FinanceIQ** adalah platform finansial canggih berbasis Artificial Intelligence yang dirancang khusus untuk memberdayakan setiap keputusan finansial Anda. Dengan berbagai Agen AI (*AI Agents*) yang menganalisis pasar, memetakan risiko, hingga mengelola kekayaan, FinanceIQ membawa kecerdasan finansial kelas institusi langsung ke genggaman Anda dengan antarmuka yang modern dan memanjakan mata.

## ✨ Fitur Unggulan

- **📈 Market Analyst Agent**: Dapatkan *insight* dan tren pasar secara mendalam dan *real-time*.
- **🛡️ Risk Profiler Agent**: Penyesuaian strategi investasi yang cerdas berdasarkan toleransi risiko Anda.
- **💼 Wealth Manager Agent**: Strategi pengelolaan kekayaan (*wealth management*) yang dipersonalisasi untuk mengembangkan portofolio Anda.
- **🎓 Financial Literacy**: Edukasi finansial interaktif yang mudah dipahami.
- **🎨 UI/UX Menawan**: Antarmuka web yang sangat responsif, modern, dan dirancang khusus untuk kenyamanan pengguna.

## 🚀 Mulai Menjalankan Proyek

FinanceIQ terbagi menjadi dua bagian utama: **Frontend** (Next.js) dan **Backend** (FastAPI).

### 💻 Frontend (Next.js)
```bash
cd frontend
npm install
npm run dev
```
Aplikasi web akan berjalan di `http://localhost:3000`.

### ⚙️ Backend (FastAPI / Python)
```bash
cd backend
python -m venv .venv
# Aktifkan virtual environment (Windows): .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
API server akan berjalan di `http://localhost:8000`.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: Python, FastAPI, LangGraph / LangChain
- **Kecerdasan Buatan**: Arsitektur Multi-Agent LLM untuk orkestrasi finansial
